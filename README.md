# brutal-age-frontend

Brutal Age AB's Marketplace — High-Performance React + Vite Storefront & Admin Portal

## Features
- **Storefront**: Brutal Age accounts, Leadership range filter (0K–900K), dynamic price slider ($200–$25,000).
- **Admin Portal**: Executive Light Theme dashboard, mobile slide-over sidebar, live database listings management, registered buyers directory, and custom requirement manager.
- **Communication Channels**: Instant checkout via WhatsApp, Line, Telegram, and WeChat.
- **Deploy Target**: Vercel Single Page Application (`vercel.json` configured).
